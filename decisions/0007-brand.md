# ADR 0007: Brand — ParcelBuddy

**Status:** accepted · 2026-07-12 (founder decision, F5)

## Decision
- **Name:** ParcelBuddy — short form "Pbuddy". User-facing surfaces say
  "ParcelBuddy"; bundle id stays `com.pbuddy.app`; domain/hosting unchanged.
- **Palette** (founder brief: "like InPost, Airbnb — somewhere there", i.e.
  between InPost's yellow-black logistics energy and Airbnb's coral
  friendliness → warm coral-orange):

| Token | Hex | Use |
|---|---|---|
| buddy-coral | `#FF5A36` | brand accent, highlights, chips, links |
| action | `#D93A17` | filled buttons (white text ≈ 4.9:1, AA) |
| ink | `#1D1D1F` | text |
| paper | `#FAF6F3` | warm page background |
| eco-green | `#0A7A4F` | reserved for CO₂e/impact only |

## Consequences
- iOS: display name "ParcelBuddy", global tint = action colour.
- Web (shop page, ops, status pages): greens → coral/action; eco-green kept
  exclusively for sustainability stats so the green claim stays visually
  distinct from brand decoration.
- Logo: not yet designed — wordmark "ParcelBuddy" in system bold until a
  designer pass; revisit before App Store listing.
